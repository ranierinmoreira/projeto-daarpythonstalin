# projeto-daarpythonstalin 🎮🐍

> Console retrô em Python com estilo inspirado nos videogames clássicos dos anos 90!
E eu tava com tempo e aproveitei para usar a IA para ajudar a desenvolver essa perola 😁😁😁

## 💡 Sobre o projeto

Este projeto recria a experiência nostálgica dos consoles de videogame clássicos (PlayStation 1, Nintendo 64, etc.) em Python. O sistema oferece uma interface completa com:

### 🎯 Funcionalidades Principais
- **Sistema de Login**: Criação de contas e autenticação de usuários
- **Minijogos Retrô**: Coleção de jogos simples e divertidos
- **Calculadora Avançada**: Operações matemáticas e funções especiais
- **Sistema de Pontuação**: Ranking e conquistas para os jogadores
- **Interface Nostálgica**: Arte ASCII, animações e cores inspiradas nos consoles clássicos

### 🎮 Minijogos Incluídos
- 🎯 **Jogo da Adivinhação**: Adivinhe o número secreto
- 🎲 **Dados da Sorte**: Teste sua sorte com os dados
- 🧠 **Teste de Memória**: Exercite sua memória
- 🎹 **Simulador de Piano**: Crie melodias simples
- 🎨 **Gerador de Arte ASCII**: Crie arte com caracteres
- 🔢 **Calculadora de Idade**: Estatísticas da sua idade

### 🧮 Calculadora Avançada
- ➕ Operações básicas (+, -, *, /, **)
- 📐 Funções matemáticas (seno, cosseno, raiz, logaritmo)
- 🔢 Conversor de bases numéricas
- 📊 Calculadora de estatísticas

## 🛠 Tecnologias utilizadas

- **Python 3.7+** (apenas bibliotecas padrão)
- **JSON** para armazenamento de dados
- **Arte ASCII** para interface visual
- **Cores ANSI** para terminal colorido
- **Sistema de arquivos** para persistência de dados

## 🚀 Como executar

### Pré-requisitos
- Python 3.7 ou superior
- Terminal com suporte a cores ANSI (recomendado)

### Instalação e Execução

1. **Clone o repositório:**
```bash
git clone <url-do-repositorio>
cd projeto-daarpythonstalin
```

2. **Execute a versão completa (recomendado):**
```bash
python main.py
```

3. **Ou execute a versão simplificada:**
```bash
python menu.py
```

### 🎮 Controles
- Use as teclas numéricas para navegar pelos menus
- Pressione `Enter` para confirmar seleções
- Use `Ctrl+C` para sair a qualquer momento

## 🐛 Solução de Problemas

### Terminal não mostra cores
- Certifique-se de que seu terminal suporta cores ANSI
- No Windows, use o PowerShell ou Windows Terminal

### Erro de permissão
- Verifique se tem permissão para criar arquivos no diretório
- Execute como administrador se necessário

### Python não encontrado
- Instale Python 3.7+ do site oficial
- Adicione Python ao PATH do sistema
